# Public Assets

This directory contains static assets served by Next.js.

## Required Assets

To match the Game Worker Solidarity website design, you need to add:

### Logo
- **Path**: `/images/GameWorkerSolidarity_Logo_Transparent.png`
- **Source**: Download from https://gameworkersolidarity.com/images/GameWorkerSolidarity_Logo_Transparent.png
- **Dimensions**: 100x100px (recommended)

### Fonts
- **Path**: `/fonts/Parabole-Regular.woff2`, `/fonts/Parabole-Regular.woff`, `/fonts/Parabole-Regular.ttf`
- **Source**: Download Parabole font files from the Game Worker Solidarity website or contact them for font files
- **Note**: The font will fallback to system fonts if these files are not available

## Color Reference

The following CSS variables are defined in `src/app/(frontend)/styles.css`:

- `--gw-pink`: #DD96FF (Primary brand color)
- `--gw-pink-light`: #FFCAD9 (Light pink variant)
- `--gw-orange`: #FF8038 (Orange accent)
- `--gw-orange-light`: #FFC58E (Light orange variant)
- `--gw-blue`: #3B97EC (Blue accent)
- `--gw-yellow`: #EBFF00 (Yellow accent)
- `--gw-background`: #F8F8F8 (Background color)
- `--gw-text-200`: rgba(0, 0, 0, 0.7) (Secondary text color)
